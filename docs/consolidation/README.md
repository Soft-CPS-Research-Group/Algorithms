# Research code provenance

The [branch inventory](branch-map.json) maps the original research branches and commits to the implementations recovered into `main`. The corresponding `archive/2026-10-26/*` tags preserve the student work and author history. To trace a recovered implementation, look up its original SHA in the inventory and inspect it with `git show <sha>`.

Use the [agent catalogue](../agent_catalogue.md) for the current implementation and export capabilities.
